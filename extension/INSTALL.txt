웹죽 데스크 설치

1. 이 ZIP을 폴더로 압축 해제합니다.
2. Chrome에서 chrome://extensions 를 엽니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
4. manifest.json 이 있는 이 폴더를 선택합니다.
5. https://crawl.nemelex.cards/ 를 새로고침합니다.

Alt G: 신앙 / Alt M: 마법 / Alt T: 투척 / Alt E: 발동
좌클릭: 사용·시전 / 우클릭: 설명
Shift+클릭 또는 ☆: 빠른 슬롯 등록 / Alt 1–6: 슬롯 사용
마법 탭 ↻: 목록 갱신 / ⚙: 기술·능력 갱신과 단축키 설정
각 칸과 전체 패널의 접힘 상태는 새로고침 후에도 유지됩니다.

몬스터 위험도와 대응 후보는 추정입니다.
저항·마법 실패율·기술·능력 정보는 마지막 조회 시점 기준입니다.
지원 사이트: crawl.nemelex.cards / Chrome 111 이상
