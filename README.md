# 웹죽 데스크 · WebJuk Desk

`https://crawl.nemelex.cards/`용 Chrome Manifest V3 확장입니다. 원본 WebTiles의 오른쪽 상태창·미니맵·몬스터 목록 아래에 **신앙 → 마법 → 투척 → 발동 → 소지품** 다섯 칸을 세로로 배치합니다. 각 칸을 따로 접거나 스크롤할 수 있습니다. 별도 사이드바나 가로 공간을 만들지 않습니다.

## 설치

1. GitHub의 **Code → Download ZIP**으로 소스를 받은 뒤 압축을 풉니다. 이미 클론했다면 저장소의 `extension` 폴더를 사용합니다.
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. `manifest.json`이 들어 있는 폴더를 선택하고 웹죽 탭을 새로고침합니다.

Chrome 111 이상이 필요합니다. Chrome Web Store에 게시된 확장이 아니므로 로컬 폴더로 설치합니다. ZIP을 그대로 선택하는 방식은 지원하지 않습니다.

설명은 툴팁으로만 표시합니다. 패널은 원본 `#stats`의 실제 너비에 고정되며 내부에서 세로 스크롤합니다. 채팅·한글 조합·입력 필드에서는 확장 단축키를 가로채지 않습니다. 장비처럼 서버가 직접 사용 동작을 제공하지 않는 항목은 설명 화면에서 장착·해제를 이어갑니다.

마법은 한 줄에 하나씩 아이콘·이름을 표시하고, 오른쪽에 성공률과 위력을 붙입니다. 성공률은 서버 실패율의 보수(`100 − 실패율`)이며 명중률과는 다릅니다. 위력은 서버가 표시한 주문력(최대치 대비 %)입니다. 아직 조회하지 않은 수치는 `—`로 표시합니다. 발동 칸에는 소지한 마법봉·기타 발동 도구와 충전량을 표시합니다.

## 몬스터 대응 정보

원본 몬스터 행 오른쪽에는 위험도를, 같은 행 아래에는 대응 수단 전체를 아이콘만으로 붙입니다. 이름·피해량·계산 근거는 툴팁에서 확인합니다. 여러 줄로 배치하며 길어지면 목록 안에서만 세로 스크롤합니다. 아이콘에 마우스를 올리면 이름·선정 근거가 나오고 클릭하면 원본 게임의 사용·시전 흐름으로 연결됩니다.

체력은 `HP 40–60%`처럼 원본 부상 플래그의 남은 비율 구간과 `평균 18`처럼 서버의 종별 평균 HP를 표시합니다. 정확한 현재·최대 HP는 전송되지 않으므로 평균값을 실제 HP로 환산하지 않습니다. 부상 없음은 100%, 이후 단계는 80–100%, 60–80%, 40–60%, 20–40%, 0–20%입니다. 각 구간의 하한은 초과, 상한은 이하(100%는 미만)이며 툴팁에 표시합니다. 같은 행에 여러 마리가 묶이면 개별 구간을 포괄한 범위를 표시하고, 하나라도 미확인이면 `HP ?`로 유지합니다.

- 기본 위험도: 서버가 보내는 몬스터 위협 등급. 현재 HP, 시야 내 적 수, 행동을 제한하는 상태 이상, 치명적 중독으로 보정합니다.
- 대응 후보: 현재 소지품·충전량, MP, 마지막으로 확인한 마법 실패율·기술 수치·능력 목록을 사용합니다. 확인한 저항이 있으면 속성 약점·저항·면역을 반영합니다.
- 위험도는 **설명 가능한 규칙에 따른 추정**입니다. 몬스터 설명에서 확인한 AC·EV 구간과 원본 주문의 방어 규칙으로 직접 피해를 보정합니다. SH·특수 상태·지형·시선은 계산하지 않으며 제외 항목을 툴팁에 표시합니다. 사거리, 신앙 비용, 몬스터의 변화한 장비·상태에 따른 사용 가능성은 원본 게임에서 최종 판단합니다.
- 몬스터의 기본 네트워크 데이터에는 속성 저항이 없습니다. 원본 몬스터 설명을 연 뒤 읽을 수 있는 `rF`, `rC`, `rPois`, `rNeg`, `rElec`, `rCorr` 표기만 캐시합니다. 알 수 없는 값은 미확인으로 유지합니다.
- 미식별 물약·두루마리를 회복·탈출용이라고 추측하지 않습니다. 우호·중립 몬스터에는 공격 후보를 표시하지 않습니다.

## 위력·피해량·의지 판정

`⚙ → 위력 ↻`는 기술, 선천적 특성, 마법 두 보기, 공격 아이템 설명, 능력 목록·설명을 차례로 조회합니다. 시전·아이템 사용·능력 실행은 하지 않으며, 능력 선택은 서버가 설명 모드임을 확인한 뒤에만 보냅니다. 키보드나 게임 화면의 마우스 입력이 들어오면 남은 조회를 중단합니다.

- **마법 전체**: 서버 메뉴의 현재 주문력·피해 주사위·사거리·실패율을 읽습니다. 원본 `spl-data.h`의 425개 정의(몬스터·이전 주문 포함)를 타일 식별자와 연결하므로 번역된 이름에도 같은 계산을 적용합니다. 주문력 %는 최대 위력 대비 값이므로 원본 최대치로 원시 위력 구간을 복원합니다.
- **투척물 및 무기**: 원본 `damage_rating()`이 현재 힘·기술·살육·장비를 반영해 계산한 공격력과 현재 공격 지연을 설명에서 읽습니다. 공격력/2는 후보 비교 지표로만 쓰며 실제 평균 피해라고 표시하지 않습니다. 다트의 독·마비 같은 부가 효과를 물리 피해로 환산하지 않습니다.
- **마법봉·기타 발동 도구**: 서버 `evoke_damage_string()`이 계산한 피해량을 읽습니다. 마법봉 원시 위력은 원본 `wand_power()`의 발동술, MP 강화 특성, 위력 상한을 적용합니다. 표시 기술의 소수점 정밀도, MP 강화 미조회, 보유한 증폭 장비의 착용 여부가 불명확하면 구간을 유지합니다.
- **공격 능력·신의 능력**: 원본 `_ability_damage_string()`을 사용하는 능력 설명에서 피해 주사위와 사거리를 읽고 실패율을 반영합니다. 신앙·기도술·레벨별 보정은 서버 계산 결과에 포함됩니다. 공격 위력이 없는 보조 능력은 별도 규칙으로 유지합니다.
- **의지 판정**: 정신붕괴·마비·매혹·변신 등 `WL_check` 주문은 원본 zap 위력 배율, `ench_power_stepdown()`의 반올림, `hex_success_chance()` 공식을 적용합니다. 몬스터 설명의 Will `+`는 1–40, `++`는 41–80처럼 구간으로 읽으며 돌파 확률도 구간입니다. 기대 피해 계산에는 정수 %로 버리기 전의 확률을 사용하여 1% 미만의 성공 가능성을 면역으로 취급하지 않습니다. 의지 면역·돌파 불가능은 제외하고, 낮은 돌파 확률은 점수를 낮춥니다. 의지 미조회 항목은 효과를 추측하지 않고 낮은 우선순위로 유지합니다.
- **AC·EV 판정**: 몬스터 설명의 AC·EV `+`는 1–5, `++`는 6–10처럼 구간으로 읽습니다. 주사위 분포의 각 결과에 AC 차감·0 하한·속성 저항 순서로 적용한 뒤 평균을 구합니다. 전격의 절반 AC, 파편의 3중 AC, 동결·정신붕괴의 AC 무시를 구분합니다. EV는 원본 `_test_beam_hit()`의 중첩 난수와 동점 명중을 반영하며, 폭발·자동 명중 공격에는 회피 확률을 곱하지 않습니다. 기본 EV만 알려지므로 투명·후광·부정확·투사체 반사 등 특수 상태는 제외합니다.

후보 점수는 승률이 아닙니다. **한 번 사용할 때의 예상 직접 피해 지표 내림차순**으로 정렬하며, 계산에 사용한 값에 구간이 있으면 하한으로 비교하고 툴팁에 전체 구간을 표시합니다. 기본식은 `Σ E[저항보정(max(0, 타격 피해 − AC 차감))] × 기본 명중률 × 시전 성공률 × 의지 돌파 확률`입니다. 속성 저항은 몬스터용 계수와 50%·70% 부분 저항, 각 피해 결과의 정수 나눗셈을 반영합니다. 예를 들어 `1d4`와 AC 2의 평균 피해는 단순히 평균에서 AC/2를 뺀 1.5가 아니라 **19/12 ≈ 1.58**입니다.

`2x…` 등의 다단 공격은 타격마다 AC를 적용한 뒤 합산합니다. 플라스마 빔의 화염·전격, 영구동토 분출의 물리·냉기 성분을 따로 계산하므로 한 속성에 면역이어도 나머지 성분을 보존합니다. 여러 타격이 같은 대상에 도달하는 것을 전제로 하며 지형·소환체 이동 등에 따른 실제 도달 횟수는 보장하지 않습니다. `/turn`, `/arc` 등 단위당 피해만 알려진 식은 단위당 수치를 표시하고 1회 총 피해 정렬값은 미확인으로 유지합니다. 벽 수·현재 대상 HP 등 해석할 수 없는 복합식은 임의의 피해량으로 바꾸지 않습니다.

공격 지연으로 나누지 않습니다. 투척물은 서버 공격력/2를 근사 비교 지표로 사용하며 피해 예측과 구분합니다. 미조회 공격 수단과 피해량이 없는 회복·탈출·보조 수단은 계산 가능한 공격 수단 뒤에 놓습니다. AC·EV·저항이나 방어 규칙을 모르면 해당 보정을 제외하고 툴팁에 미확인을 표시합니다. 소수점 배율·나눗셈이 있는 피해식은 근사로 표시합니다. SH, 지속 피해·추가 효과, 지형·시선, 몬스터의 특수 면역·상태에 따른 실제 피해량과 승률은 계산하지 않습니다. 조회 값은 마지막 갱신 시점 기준이며 훈련·장비·신앙·상태가 변하면 다시 갱신해야 합니다.

## 신앙

마법보다 위에 신앙 칸을 배치합니다. 신 이름, 신앙 범위·참회 상태, 서버가 현재 제공하는 신의 능력·비용·성공률·피해량을 표시합니다. `↻`는 능력 목록 조회, `◇`는 원본 `^` 신앙 정보입니다. 능력 우클릭은 설명, 좌클릭은 원본 실행 흐름으로 연결합니다. `Alt G`로 칸을 펼칩니다.

서버는 정확한 내부 신앙값이 아닌 `piety_rank`를 보냅니다. 일반 신의 0–6성 범위는 **0–29 / 30–49 / 50–74 / 75–99 / 100–119 / 120–159 / 160–200**입니다. 좀은 일반 신앙으로 환산하지 않고 호감 등급을 표시하며, 고자그는 보유 금화를 표시합니다. 정확한 값이나 능력 사용 후 신앙을 역산해 추측하지 않습니다.

## 데이터 갱신 방식

소지품은 `player.inv` 변경 메시지를 따라 실시간으로 갱신합니다. 0.35 트렁크의 52번 이후 소모품 슬롯도 포함하며, 슬롯별 단축키는 서버 값을 사용합니다.

마법·능력·기술 전체 목록은 기본 `player` 메시지에 없습니다. 원본 메뉴를 조회해 얻은 값을 세션에 보관합니다. 갱신 버튼은 해당 메뉴를 열고 응답을 읽은 뒤 `Esc`로 닫습니다. 마법은 `!`로 실패율·주문력 두 보기를 읽어 합칩니다. 기술 조회는 훈련 선택 키를 보내지 않습니다. 마법·능력을 실행할 때는 서버 메뉴를 다시 열어 현재 단축키로 선택합니다. 시전·대상 지정을 자동으로 확정하지 않습니다. 목록의 수치와 저항·기술 정보는 마지막 조회 시점 기준입니다.

관전·연결 끊김·다른 메뉴·대상 지정 중에는 실행을 막습니다. 키보드 입력이 들어오면 대기 중인 자동 선택을 취소합니다. 재접속·새 게임 클라이언트 수신 시 목록 캐시를 비웁니다.

## 개발 및 검증

런타임 라이브러리와 빌드 과정이 없습니다. Node 20 이상에서:

```sh
npm test
npm run check
npm run package
npm run demo
```

데모는 `http://127.0.0.1:4173`에서 실행됩니다. 테스트 캐릭터와 결정적인 WebTiles 메시지 fixture를 사용하며 실제 서버 계정이나 턴에 접근하지 않습니다. `dist`와 `artifacts`는 생성물이라 Git에서 제외했습니다.

소스 구분:

- `extension/bridge.js`: 페이지 MAIN world에서 이미 로드된 RequireJS 모듈의 공개 함수·현재 플레이어 상태를 읽습니다. 기존 `comm.handle_message`를 보존하면서 응답을 관찰하며 새로운 WebSocket을 만들지 않습니다.
- `extension/content.js`: isolated world의 최소 UI, 단축키, Chrome 로컬 설정.
- `extension/core.js`: 목록 정규화·메뉴 추적.
- `extension/advisor.js`: 위험도·후보 선정 규칙.
- `extension/combat.js`: 위력·피해 표현·의지 확률·신앙 범위 계산.
- `extension/power-data.js`: 원본 정의에서 생성한 주문 메타데이터. `node scripts/generate-power-data.cjs /path/to/crawl-ref/source`로 다시 생성할 수 있습니다.
- `tests`: 슬롯 확장, 부분 메뉴, 연결 상태, 시전 시 단축키 변경, 조회 취소, 기술·능력 조회, 저항·MP·아이템 조건 검증.

`storage` 권한과 `crawl.nemelex.cards` 접근만 요청합니다. 로그인 정보는 읽거나 저장하지 않으며 외부 분석 서버·원격 실행 코드·텔레메트리가 없습니다. 페이지와 확장 사이 메시지는 같은 사이트의 스크립트에서도 접근할 수 있으므로 별도의 보안 경계로 취급하지 않습니다.

## 실서버 검증

2026-10-13 네멜렉스 0.35 트렁크의 한국어 UI에서 다음을 확인했습니다.

- 소지품·투척물 표시, 서버 마법 목록 갱신, 한국어 기술 수치 조회와 메뉴 복귀.
- 마법 성공률·위력 두 보기 조회(실패율 36% → 성공률 64%, 서버 위력 8%), 발동 아이템 분류, 신앙을 포함한 다섯 칸 세로 배열과 개별 접기.
- 마법 우클릭 시 원본 설명 표시.
- 투척 및 마법 아이콘에서 원본 대상 지정까지 연결한 뒤 Esc로 취소. 턴, MP, 투척물 수량이 보존됨을 확인했습니다.
- 검증 화면에서 원본 상태창과 확장 패널의 너비가 모두 405px이며 게임 영역 침범과 가로 넘침이 없었습니다.
- 전체 위력 조회 후 기술·특성·마법·공격 아이템·능력 설명을 읽고 원래 게임 화면으로 복귀했습니다. 턴·시간·MP·아이템 수량 및 충전량이 유지됐습니다.
- 몬스터별 대응 수단은 이름 없이 아이콘으로만 표시되며, 워프 마법봉 3d8 → 불꽃 마법봉 2d6 → 자벨린 공격력 13 순서로 정렬됐습니다.

타격·시전 결과를 확정하는 동작과 실제 피해량·승률은 검증 범위에 포함하지 않습니다.
